About This Project

Campus Paws was made as a Web Technology project. The idea came because we saw many dogs in our campus that nobody takes care of. If a dog gets hurt, most people don't know who to tell. With this website anyone can upload a photo and describe the problem.

Technologies Used

  1. HTML - for the structure of the pages
  2. CSS - for colours, layout and design
  3. JavaScript - for the dog list, search, form checking and saving reports
